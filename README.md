# Manga Forge

Local-first desktop studio that turns written story prose into visual manga
storyboards, panels, and living character/world databases. Runs fully offline
against local AI endpoints (Ollama + ComfyUI), optimized for a 16 GB machine.

**Stack:** Tauri 2 (Rust) · React + TypeScript + Vite · Tailwind + shadcn/ui ·
Drizzle ORM + SQLite · React-Konva · Zustand.

## First-time setup (WSL / Ubuntu)

### 1. System dependencies

```bash
sudo apt update
sudo apt install -y \
  build-essential curl wget file pkg-config \
  libwebkit2gtk-4.1-dev \
  libssl-dev \
  libgtk-3-dev \
  librsvg2-dev \
  libayatana-appindicator3-dev \
  libsoup-3.0-dev \
  libjavascriptcoregtk-4.1-dev
```

### 2. Rust toolchain

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y
source "$HOME/.cargo/env"
rustc --version   # verify
```

### 3. Project dependencies

```bash
cd /home/boink/manga
npm install
```

App icons are already generated and committed in `src-tauri/icons/` (brand mark).
To replace them, drop a 1024×1024 PNG in and run `npm run tauri icon path/to/icon.png`.

### 4. Database migration — already wired

The baseline migration `src-tauri/migrations/0000_init.sql` (matches
`src/db/schema.ts`) is already registered in `src-tauri/src/lib.rs` and runs
automatically on first launch — **no `db:generate` step needed to get started.**

For a *future* schema change, add a new `src-tauri/migrations/NNNN_name.sql`
with just the delta DDL and append a `Migration { version: N, … }` entry in
`lib.rs`. You can hand-write the delta, or produce it with `npm run db:generate`
(note: because `0000_init.sql` was authored by hand, drizzle-kit has no baseline
snapshot — its first run regenerates the whole schema, so treat its output as a
starting point to trim to the delta, or re-baseline on an empty DB).

### 5. Run the app

```bash
npm run app:dev
```

> **WSLg note:** GUI apps need WSLg (bundled with recent Windows 11 / updated
> WSL). If the window doesn't appear, run `wsl --update` from PowerShell. Ollama
> and ComfyUI may run either inside WSL or natively on Windows — the adapter
> layer targets `127.0.0.1:11434` / `127.0.0.1:8188` either way.

### 6. Build an installable app

```bash
npm run app:build
```

Produces a standalone installer (no terminal needed afterwards) in
`src-tauri/target/release/bundle/`:

- **Linux:** `appimage/Manga Forge_1.1.0_amd64.AppImage` (double-click to run) and
  `deb/manga-forge_1.1.0_amd64.deb` (`sudo dpkg -i …`).
- **Windows / macOS:** run the same command on that OS to get `.msi`/`.exe` or
  `.dmg` (icons for all three are already bundled).

The first build compiles the Rust side and takes several minutes; subsequent
builds are incremental. The release profile is tuned for size/RAM
(`lto`, `opt-level = "s"`, `strip`).

## Database

The schema is the single source of truth: [`src/db/schema.ts`](src/db/schema.ts).
Migrations are generated by drizzle-kit and applied at startup by the Tauri SQL
plugin. The frontend talks to SQLite through Drizzle's `sqlite-proxy` driver
([`src/db/client.ts`](src/db/client.ts)), so there is exactly one native SQLite
handle in the Rust process.

```ts
import { db, projects } from '@/db';
const all = await db.select().from(projects);
```

### V1.0 finalization
- **Story → Storyboard bridge:** the Agents tab turns parsed beats into a storyboard
  page (auto-layout, per-panel camera + action prompt, dialogue bubbles, character layers).
- **Startup / memory:** views are `React.lazy` code-split and the export libs (jsPDF/JSZip)
  are dynamic-imported, so the 1.38 MB monolith is gone — Konva and export code stay off the
  startup path until used (better fit for the 16 GB target).
- **Robustness:** app-level `ErrorBoundary`.
- **Tests:** `npm test` (Vitest) covers the prompt compiler, layout math, and agent JSON parsing.

### V1.1
- **Relational scene cast:** the Advanced editor's "Present characters" is backed by
  the `scene_characters` join table (stable character IDs, per-scene outfit/expression
  state), with a one-shot migration of any legacy name lists.
- **Storyboard canvas:** anchorable speech-bubble tails (drag the tip; it re-bases to
  the nearest edge), a page **bleed** trim guide + control, and panel **drag-snap** to
  sibling edges and the gutter grid.
- **Migration 0001:** adds `pages.bleed` (wired into `lib.rs` as version 2) — the first
  hand-written delta on top of the baseline.
- **Tests:** suite expanded to 28 — snap geometry, join-table reconciliation, and the
  workspace store's scene-character flow.

Verification gate (all green): `npm test` · `npm run typecheck` · `npm run build`,
also enforced in CI ([`.github/workflows/ci.yml`](.github/workflows/ci.yml)) on every
push and PR to `master`. The Rust/GUI side (`npm run app:dev`) requires the Rust
toolchain + WSLg and is run locally.
